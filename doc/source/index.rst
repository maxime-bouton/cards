Welcome to mcmc documentation
==============================

This library is focussed on the implementation of SMPD distributed MCMC algorithms on multiple GPUs, with specific applications to imaging inverse problems.

The library currently contains codes to reproduce the experiments reported in :cite:p:`Bouton2025submitted`.


.. warning::

   This project is under active development, and the API my evolve significantly until version ``1.0``.
..    - A complete code coverage report is available `here <../coverage_html_report/index.html#http://>`_.
